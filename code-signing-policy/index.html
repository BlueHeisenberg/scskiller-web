Code signing policy

Last updated: 22 November 2026

Status

SCSKiller isn't code-signed yet. Windows shows "Unknown publisher", and the first run will probably show SmartScreen's "Windows protected your PC": click More info, then Run anyway. Updates never show it.

Each release lists the SHA-256 of its downloads. Compare it with the file's (PowerShell: Get-FileHash <file>).

What will be signed

Once signing is set up, only binaries built from the public repository's source by its GitHub Actions release workflow, from a stable release tag:

  • SCSKiller.exe, the app
  • cli\scskiller.exe and cli\scskillerw.exe, the command line
  • native\scskiller_warm.exe and native\segheap\scskiller_warm.exe, the compiler that runs outside the game
  • native\d3d12.dll, the optional recorder
  • SCSKiller-Setup.exe and Update.exe

Upstream binaries and runtimes in the package aren't signed by this project. Alpha and beta builds aren't signed under this policy. Every signed file carries the product name SCSKiller and the release's version.

Roles

Authorthe maintainer
Reviewerthe maintainer, for every external contribution before it's merged
Approverthe maintainer, for each signing request

Contributions are reviewed in public pull requests. Every signing request will be approved by hand. All members use multi-factor authentication on GitHub.
