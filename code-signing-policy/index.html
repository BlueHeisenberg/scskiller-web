Code signing policy

Last updated: 28 September 2026

Status

SCSKiller will apply to the SignPath Foundation for free code signing. Until it is granted, releases are unsigned, and Windows may warn you when you run the installer.

What is signed

  • Stable releases only: the binaries built by the public repository's GitHub Actions workflow, from the tagged public source.
  • Beta and alpha builds are not signed under this policy.

Privacy

SCSKiller connects to the network only to:

  • show its welcome text on first start;
  • check for and download updates;
  • download public files some games need to be read;
  • sign in with Patreon, and use the community database, if you choose to;
  • share recordings, if you opt in.

Details are in the privacy policy.
